# گزارش بازطراحی رابط کاربری PartnerConsole

## خلاصه اجرایی و وضعیت نهایی

رابط کاربری مدیر و همکار در شاخهٔ محلی `codex/quiet-luxury-v2` بازطراحی شد. مبنا کامیت `7768c39c91141b27a1ae0bec57674b457187ebfb` و کامیت اجرایی آزموده‌شده `1319b04b234532ad2c2c10e4dd1a681dea89ec86` است. این نسخه برای بازبینی محلی آماده است. آزمون نصب و ارتقای روی اوبونتو هنوز انجام نشده است.

تمام شش سند متنی بسته خوانده شدند. ۳۹ برد اصلی با ابعاد ۳۸۴۰×۲۱۶۰ فهرست شدند و نمای برنامهٔ هر برد جداگانه با تصویر واقعی Chromium مقایسه شد. نشان‌های سیستم‌عامل، قاب تزئینی گوشی و داده‌های نمایشی مرجع معیار مقایسهٔ محصول نبودند. مقایسه بر اساس برش محتوای برنامه، سلسله‌مراتب، چیدمان و مقیاس بصری انجام شد.

## تغییرات انجام‌شده

- پوسته و ناوبری هر دو نقش، ورود، دکمه‌ها، جدول‌ها، کارت‌ها، پیام‌ها، تمرکز صفحه‌کلید و نوار پایین موبایل با اجزای مشترک و پالت یشمی و گرم پیاده شدند.
- مدیریت پنل، ساخت محصول، پروفایل و اعتبار و تعدیل همکار، جزئیات اشتراک مدیر و رسیدگی به عملیات به مسیرها و حالت‌های روشن منتقل شدند. مسیرهای قبلی و شرط‌های مجوز API حفظ شدند.
- داشبورد و نرخ و اعتبار محصولات همکار، فهرست و تاریخچه، فرم ساخت و پیش‌فاکتور، تب‌های جزئیات و هفت حالت مدیریت اشتراک با API فعلی کار می‌کنند.
- مرور موبایل از ثبت خرید جدا شد. مقادیر تأیید از همان پاسخ API می‌آیند. تغییر نشست و اختلاف پیش‌فاکتور امکان ثبت با تأیید قدیمی را از بین می‌برند. قفل ارسال هم‌زمان و ادامهٔ عملیات قبلی حفظ شد.
- برای ترک درون‌برنامه‌ای فرم خرید، رمز پنل، یادداشت اشتراک و توضیح رسیدگی، هشدار قابل‌لغو اضافه شد. اطلاعات فرم تنها در حافظهٔ همان صفحه می‌مانند.
- منطق بک‌اند، مایگریشن‌ها، احراز هویت و کنترل‌های مشترک تراکنش، تنظیمات، اسکریپت‌های نصاب و وابستگی‌های پروژه تغییری ندارند. تغییر فهرست اجرایی برای ورود اجزای تازه به بسته لازم بود.
