# Backup داخل پوشهٔ نصب

`bash scripts/backup.sh` فقط وقتی API و وب ایستاده‌اند کار می‌کند و خروجی را در `backups/` می‌نویسد. فایل موقت اتصال MySQL در `runtime/tmp` با دسترسی محدود ساخته و بعد از فرمان حذف می‌شود. رمز در آرگومان فرمان و در خروجی چاپ نمی‌شود.

SQLite توسعهٔ `backend/data/partner.db` پذیرفته نمی‌شود.

برای MySQL، `mysqldump` باید از قبل نصب باشد. این اسکریپت آن را نصب نمی‌کند. dump شامل `--single-transaction` است و جای پنجرهٔ نگهداری را نمی‌گیرد: اول `bash stop.sh`، بعد backup.

فایل خروجی mode 600 است. کلیدهای `config/api.env` داخل dump نیستند. بدون همان `SECRET_KEY` یا `PANEL_ENCRYPTION_KEY`، رمز ذخیره‌شدهٔ پنل بعد از بازیابی قابل استفاده نیست. کلید را کنار dump نگذارید.

بازیابی را اول روی schema یا فایل جدا تمرین کنید. `version_num`، جمع مانده، اعتبار محصول، `v2_user_id`، journal، pending، attention و lease را با مبدأ مقایسه کنید. بعد مقصد را در `config/api.env` بگذارید و `bash start.sh` را اجرا کنید.

برای بازیابی داده به نسخهٔ پشتیبان دیتابیس و نسخهٔ جداگانهٔ تنظیمات همان نصب نیاز است.
