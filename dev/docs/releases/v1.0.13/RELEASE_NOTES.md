# PartnerConsole v1.0.13

## اعتبار برگشتی اشتراک

اعتبار حجم و روزِ حاصل از کاهش یا حذف اشتراک تا تأیید قطعی پنل رزرو می‌شود. پس از تأیید، اعتبار محصول، دفترکل و وضعیت نهایی عملیات با هم ثبت می‌شوند. بازیابی و تلاش مجدد از ثبت تکراری اعتبار جلوگیری می‌کنند. عملیات ناتمام نسخهٔ قبلی با همان قرارداد مالی زمان ایجادشان بازیابی می‌شوند.

## رابط همکار و مدیریت

ظاهر فارسی و راست‌به‌چپ داشبورد، پیش‌فاکتور، تاریخچه و صفحات رسیدگی یکپارچه شده است. پیش‌فاکتور میان مبلغ رزروشده و اعتبار قابل‌مصرف تمایز روشنی دارد. یادداشت تصمیم مدیر یک بار در تاریخچهٔ عملیات نمایش داده می‌شود و پیام خطای مستقل همچنان در جزئیات قابل مشاهده است. فونت وزیرمتن با فایل‌های تأییدشده ارائه می‌شود.
